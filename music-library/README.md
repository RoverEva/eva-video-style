# music-library

Optional. Used only when `background_music` is `auto` or `manual` (the default is `none`: no music).

```text
music-library/
├── background/
│   └── open-lofi/        Open Lo-Fi tracks (background beds)
├── jingles/
│   └── kenney/           Kenney Music Jingles, one sub-folder per family: 8bit hit pizzicato sax steel
├── catalog.json          generated by `scripts/music.py analyze` (local, not committed)
├── tags.json             optional manual tags (copy tags.example.json)
└── LICENSES.md
```

## Import (links, no copies)

```bash
python3 scripts/music.py import --lofi ~/Downloads/openlofi --kenney ~/Downloads/kenney_music-jingles
python3 scripts/music.py analyze --limit 3     # MVP: 3 beds + 3 jingles (one per family)
python3 scripts/music.py analyze               # later: the whole library; already-analysed files are skipped
```

`import` creates symlinks to your downloads (add `--copy` to copy instead). `analyze` decodes each file once with
FFmpeg and caches the result in `catalog.json`, keyed by file size and modification time, so later runs only
analyse new or changed files.

## catalog.json format

```json
{"version": 1,
 "tracks": {
  "background/open-lofi/cursor-after-midnight.mp3": {
    "type": "background", "duration": 182.3, "bpm": 84.1, "beat": 0.7134, "first_beat": 0.21,
    "downbeats": [0.21, 3.06], "phrase_starts": [11.6, 17.3],
    "energy": [12, 40, 63], "energy_median": 68.0, "energy_std": 6.2,
    "intro_end": 9, "outro_start": 171, "climax": [88, 111],
    "tags": ["focus", "medium", "night", "steady", "tech"], "loudness_db": -17.9,
    "source": "Open Lo-Fi", "license": "UNVERIFIED", "key": "4381203:1760000000"},
  "jingles/kenney/hit/jingles_HIT00.ogg": {
    "type": "jingle", "family": "hit", "duration": 0.62, "peak_at": 0.01, "tail": 0.05,
    "roles": ["transition", "highlight"], "loudness_db": -19.4, "source": "Kenney Music Jingles (kenney.nl)", "license": "CC0-1.0"}},
 "licenses": {}}
```

- `energy`: loudness per second, 0–100, relative to the track's own loud level.
- `phrase_starts`: downbeats every two bars after the intro, the only places a cut may start.
- `climax`: the loudest 8-bar window, in seconds; highlights are steered towards it.
- `tags`: mood words from the title plus `calm` / `medium` / `upbeat` and `steady` from the analysis. `tags.json` replaces them.
